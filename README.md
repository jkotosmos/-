# 💌 Письмо для тебя

Сайт в одном файле: `index.html` (фото встроено внутрь).

**Сценарий:** конверт с печатью → письмо, которое проявляется слово за словом → вопрос «Ты согласна встречаться со мной?»

- **Да** — салют из сердечек и её портрет, собранный из слов «ЛЮБЛЮ» (коснись портрета, чтобы проявилось настоящее фото).
- **Нет** — шуточное «Удаляем файлы с телефона…» до 100%, потом «Шучу ♡» и возврат к вопросу. Кнопка «Нет» с каждым разом уменьшается, а «Да» растёт.

## Как поменять текст

Открой `index.html` и найди комментарий `✎ ТЕКСТ ПИСЬМА` — обращение, абзацы, подпись и вопрос идут подряд обычным текстом.

## Как открыть

Достаточно открыть `index.html` в браузере. Шрифты подгружаются из Google Fonts, поэтому нужен интернет.
